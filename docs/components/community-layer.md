# Community Layer

The **engagement surface** of the exchange — where the people behind the data interact.

## Capabilities

- **Discussions** — question-and-answer threads attached to datasets and topics, with nested comment threads, votes, emoji reactions, bookmarks, file attachments, and full-text search — so consumers can ask providers about data semantics, quality, and usage.
- **Challenges** — providers and platform operators publish data challenges with a full competition lifecycle (draft → active → closed); participants join, submit solutions built on exchange data, receive scores and feedback, and appear on a leaderboard.
- **Moderation** — a review queue for new content (pending → approved/rejected/hidden), comment reporting, and admin workflows, exercised by organisation and platform admins.

## Why it is part of the platform

A data exchange is only useful if consumers can understand the data they find. Keeping discussion alongside the catalogue — under the same identity and organisation model — means questions, answers, and challenge results stay connected to the resources they are about.

| Object storage | Discussion and submission attachments |
